# データ調査（Phase 1a）: 行政事業レビュー見える化サイト 2024年度 CSV

調査日: 2026-09-22 / 対象: 2024年度レビューシート CSV（データ基準日 2025-02-14）
出典: 行政事業レビュー見える化サイト（内閣官房行政改革推進本部事務局）のデータを加工して作成

## 0. 結論（先に要点）

- **予算ライフサイクル 6 段階はすべて 1 枚のレビューシート内で閉じる。** 要求・成立・執行・決算は `2-1`、評価と翌年度反映は `4-1`、成果目標と実績は `3-1` にあり、いずれも `予算事業ID` で結合できる。Phase 1 の「1事業を1画面」は実現可能。
- **年度をまたぐ追跡（Phase 3）も見込みあり。** `予算事業ID` は年度をまたいで同一事業を指す永続 ID である（2024→2025 で 5,664 件中 5,231 件が同一 ID で継続。消えた 433 件のうち 340 件は 2023 年度終了予定事業）。
- **実装上の難所は 3 つ。** (a) `2-1` は「合計行 + 会計別行」の 2 層構造、(b) 執行実績は「事業年度 − 1」までしかない（2024 年度シートの執行は FY2023 が最新）、(c) `5-1` は 3 階層のネストを 1 表に平坦化している。

## 1. 取得方法

- ダウンロードページ（`/download-csv/2024`）は SPA で、静的 HTML には ZIP リンクがない。JS バンドル内のルーティング定義から、配布 URL は次の形式と判明した。
  - `https://rssystem.go.jp/files/{年度}/rs/{ファイル名}.zip`（ファイル名は下表の 15 種。URL エンコードが必要）
  - 各 ZIP は CSV 1 本を含む。年度単位の一括 ZIP はない。
- 2025 年度も同じ 15 ファイル構成で、`1-2` のヘッダは 2024 と完全一致した。
- 利用規約は「公共データ利用規約（第1.0版）（PDL1.0）」準拠。出典記載が必須で、加工した場合は「〜のデータを加工して作成」の旨を書く。法人番号（国税庁）と法令名（e-Gov）は外部提供元の条件に従う。

## 3. キーと結合

- **一意キーは `予算事業ID`**（整数文字列、1〜21059、欠番あり）。2024 年度の事業数は **5,664**。
- 全 15 ファイルの `予算事業ID` は `1-2` の集合と完全一致した（どのファイルにも `1-2` にない ID はなく、`1-2` にあってどこかのファイルに欠ける ID もない。行のない事業は空欄 1 行で存在する）。
- 結合は `予算事業ID` のみで十分。`事業年度` は同一年度の CSV 内では定数で、複数年度を扱うとき（Phase 3）に複合キー `(事業年度, 予算事業ID)` になる。
- `1-2` の `旧事業番号` は 5,948 件中 116 件しか埋まっておらず（2025 年度は 7 件）、年度間の追跡キーには使えない。追跡は `予算事業ID` で行う。
- **`1-2` の重複行（255 ID）は `主要経費` だけが異なる。** 主要経費が複数ある事業が 1 行ずつ展開されている。事業マスタとして使うときは `主要経費` を集約する。
- **`4-1` の重複行（28 ID）は「過去に受けた指摘事項」「その他の指摘事項」の列だけが異なる。** 評価本体（点検結果・所見・反映状況・反映額）は同一なので、指摘事項を配列に畳めば 1:1 になる（ただし `反映額（特別会計）` が異なる ID が 1 件あり、要注意）。

## 4. ライフサイクル各段階と列の対応

### 4.1 `2-1` の構造（最重要）

- 1 事業 × 1 予算年度につき **「合計行」1 行 + 「会計別行」1 行以上** で構成される。
  - 合計行: `会計区分` が空。`当初予算（合計）` 〜 `翌年度要求額（合計）`（列 14〜22）が埋まり、列 28〜42 は空。
  - 会計別行: `会計区分`（一般会計/特別会計）と `会計`・`勘定` が入り、列 28〜42（`当初予算, 第1〜5次補正予算, 前年度から繰越し, 予備費等1〜4, 歳出予算現額, 執行額, 翌年度要求額, 要望額`）が埋まる。
  - 合計行の値 = 会計別行の合計であることを全 18,522 グループで検証し、**不一致 0 件**。合計行が空で二重に存在するグループが 2 件あった（`6201/2022`, `18717/2024`）。
- `予算年度` は **2021〜2024 の 4 年分**（サイトの注記どおり「過去データは 2021 年度以降」）。4 年そろう事業 3,776 件、1 年のみ 661 件（新規事業）。
- **執行額は予算年度 2024 では全件 0。** 2024 年度シートは FY2024 進行中（2024 年 8 月頃）に作成されるため、執行実績の最新は **予算年度 2023**。
- `翌年度要求額（合計）` は予算年度 2024 の行で全 5,664 件に値があり、これが **FY2025 概算要求**。予算年度 2023 の行の同列が FY2024 概算要求（= FY2024 当初予算の「要求」側）。
- `要望額` は要求額とは別枠（重要政策推進枠などの要望）で、2024 年度 1,511 行に値がある。`主な増減理由` に「重要政策推進枠：…」のように枠名が書かれる。
- `執行率` = `執行額 / 歳出予算現額` を小数（0.797 など）で保持。全 11,652 行で再計算と一致。

## 5. 金額の単位と表記

- 金額はすべて **円単位の整数**（例: 当初予算 28,854,000）。千円・百万円ではない。予算年度 2024 の当初予算（合計）を全事業で足すと約 121 兆円で、一般会計・特別会計の規模と整合する。
- 桁区切りカンマなし。ただし `2-1` の `翌年度要求額（合計）` だけは `34482000.0` のように小数点付き文字列。
- `執行率`・`達成率` は小数または整数の文字列。`3-1` の年度列は数値も文字列（`1` = 目標年度フラグ）も入る。
- `反映額` は負値（減額）で記入。

## 6. データ品質で気づいた点

1. **`5-1` の数値列に末尾スペース**（`金額` 98,159 件、`法人番号` 134,911 件など）。他ファイルにはない。パーサで `TrimSpace` 必須。
2. **`執行額 > 歳出予算現額` が 468 グループ**（予算年度 ≤ 2023 の合計行）。大半は `現額 = 0` で執行だけある事業で、予算が別事業に一括計上されているケースとみられる。導出した不用額が負になるので、`現額 = 0` のときは不用額を「算出不能」と表示する。
3. **`翌年度繰越 > 現額 − 執行` が 198 グループ**。同様に不用額が負になる。原因は未特定。
4. **空欄と 0 の区別。** `2-1` の合計行は値が「空」か「整数」のどちらかで、0 は明示的に `0`。空はその年度の行が存在しないケース（新規事業の過去年度など）。
5. **ダッシュ表記の揺れ。** `4-1` の自由記述に `-`, `ー`, `－`, `--`, `ｰ`, `―`, `‐` が混在（「該当なし」の意）。表示時は空扱いに正規化する。
6. **`3-1` の `アウトカムの期間` に `3.長期` と `長期` が混在**（後者 8 件）。
7. **`1-2` の `事業開始年度`・`事業終了（予定）年度` は空が多い**（終了予定なしの事業は空）。
8. **`5-1` は 3 階層を平坦化**しており、同じ支出先について「合計行」（`支出先の合計支出額` あり）と「契約行」（`金額` あり）が別行になる。単純合計すると二重計上になる。
9. **`4-1` の `事業所管部局による点検・改善ー点検結果` は 413 件が空**、外部有識者点検は 3,837 件が「対象外」。評価段階は事業によって薄い。
10. ファイル名に全角記号（`・`、`、`）を含むため、URL エンコードとファイルシステム上の扱いに注意。

## 7. 表示方式の提案

**CLI のテキスト出力を先に作り、同じ構造体から静的 HTML を生成する 2 段構え**を提案する。

- Phase 1b では `zailoop show <予算事業ID>` で 6 段階を縦に並べた表を標準出力に出す。テストしやすく、対応表の検証がそのまま golden test になる。
- 同じ `Lifecycle` 構造体から `zailoop html <ID> -o out.html` で単一ファイルの静的 HTML を出す。Phase 2 以降の横断ダッシュボードは「全事業分の HTML または JSON を生成して静的配信」に自然に拡張できる。
- Web サーバは Phase 1 では持たない（デプロイ・定期実行はスコープ外）。

## 8. Phase 1b への申し送り

- 文字コード変換は不要。**外部依存なし（stdlib のみ）で実装できる見込み。**
- 取得スクリプトは 15 ファイルを 1 回ずつ取得し、既存ファイルがあればスキップする。年度は引数化する（2025 年度も同構成）。
- パーサは `encoding/csv` に BOM 除去と `TrimSpace` を足す。`2-1` は合計行と会計別行を分けて読む。
- 「最新の確定年度 N = 事業年度 − 1」を定数ではなくデータ（執行額が非ゼロの最大予算年度）から決める。
- 不用額の導出は `現額 = 0` のときに「—」を出す。
